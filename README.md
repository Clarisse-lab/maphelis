# MAPHEL — Funil de Aplicação

Estrutura estática pronta para Netlify:

- `/` — Página de Aplicação
- `/formulario/` — Formulário multi-etapas com Netlify Forms
- `/obrigado/` — Página de Obrigado

## Publicação no Netlify
Conecte este repositório ao Netlify. Não é necessário comando de build; o diretório de publicação é a raiz (`.`).
